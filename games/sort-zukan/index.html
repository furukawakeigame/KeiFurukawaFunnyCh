ソート図鑑

14種類のソートアルゴリズムの動きと得意・苦手。並び始めを変えて、同時に走らせて比べられます。

比較 入れ替え・書き込み カードの数字は「比較の回数 / 書き込みの回数」

くらべる

n は要素の数。下の「今回の結果」は、選んだ並び始め（40個）で実際に数えた比較の回数。並び始めを変えると更新されます。

ことば

計算量 O(n²) / O(n log n)：要素が増えたときに手間がどれくらい増えるかの目安。1000個なら n² は100万、n log n は約1万。

安定：同じ値どうしの順番が、ソートしたあとも元のまま保たれること。名簿を「点数順」に並べ直したとき、同点の人が名前順のまま残る、など。

追加メモリ：並べ替えのために、元の配列とは別に必要な場所。O(1) ならほぼ要らない（その場で並べ替えられる）。
